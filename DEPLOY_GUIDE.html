方式一：立即在浏览器中玩（推荐）

点击下面的按钮直接启动本地服务器：

▶️ 立即开始游戏

在浏览器中直接打开游戏

方式二：启动本地服务器

在终端中运行以下命令：

cd wuxia-card-game
python3 -m http.server 8080

然后在浏览器中访问：http://localhost:8080

方式三：部署到 Vercel（推荐）

为什么要部署到 Vercel？

  • ✅ 全球 CDN，访问速度快
  • ✅ 免费 100GB/月 流量
  • ✅ 自动 HTTPS
  • ✅ 自动部署（Git push 后自动更新）
  • ✅ 自定义域名

步骤 1：创建 GitHub 仓库

1. 访问 https://github.com/new

2. 创建新仓库，命名为 wuxia-card-game

3. 选择 Public 或 Private

4. 点击"Create repository"

步骤 2：推送代码

cd wuxia-card-game
git init
git add .
git commit -m "Initial commit: 江湖行 Roguelike 卡牌游戏"
git branch -M main
git remote add origin https://github.com/你的用户名/wuxia-card-game.git
git push -u origin main

步骤 3：部署到 Vercel

1. 访问 https://vercel.com

2. 注册或登录（可以用 GitHub 账号登录）

3. 点击"Add New Project"

4. 导入你的 GitHub 仓库

5. Vercel 会自动检测配置

6. 点击"Deploy"

部署完成后，Vercel 会提供一个链接，如：https://wuxia-card-game.vercel.app

方式四：部署到 GitHub Pages（免费）

1. 创建 GitHub 仓库（同上）

2. 推送代码（同上）

3. 访问你的 GitHub 仓库 → Settings → Pages

4. 在"Source"下选择"main"分支

5. 点击"Save"

访问链接：https://你的用户名.github.io/wuxia-card-game/

⚠️ 注意事项

  • 如果你没有 GitHub 账号，需要先注册一个
  • Vercel 和 GitHub Pages 都是完全免费的
  • 部署后，游戏链接可以分享给任何人
  • 每次修改代码后，推送到 GitHub 就会自动更新

💡 推荐选择

  • Vercel：速度最快，CDN 全球覆盖，推荐使用
  • GitHub Pages：完全免费，适合个人项目

🚀 开始部署吧！
