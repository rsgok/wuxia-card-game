# 江湖行 - 武侠 Roguelike 卡牌游戏

一个基于网页的 Roguelike 卡牌对战游戏，灵感来自 Slay the Spire。

## 快速开始

1. 在浏览器中打开 `index.html` 文件
2. 选择你的武学门派（剑客、拳师、医师）
3. 在地图上选择路线前进
4. 使用卡牌击败敌人、购买装备、应对事件
5. 挑战 Boss，最终击败武林盟主

## 游戏特性

### 三大武学门派

- **剑客** - 专精连击和爆发伤害
  - 特色：剑气系统、连击卡牌、高伤害
  
- **拳师** - 擅长防御和反击
  - 特色：铁布衫、力量提升、肉盾风格
  
- **医师** - 擅长治疗和状态控制
  - 特色：持续治疗、中毒控制、生存能力强

### Roguelike 进度

- **3 层关卡**：江湖边缘 → 门派地盘 → 武林深处
- **分叉路径地图**：每层 6-8 列，每列 2-3 个节点
- **6 种节点类型**：
  - ⚔️ 战斗、⭐ 精英、👑 Boss
  - 🏪 商店、❓ 事件、⛺ 休息
- **永久死亡**：失败后从第一层重新开始

### 卡牌系统

**30+ 张卡牌**，分为 5 种类型：

- **攻击卡** - 造成伤害（劈空掌、剑气纵横、独孤九剑等）
- **防御卡** - 获得护甲（铁布衫、金钟罩、剑盾防御等）
- **能力卡** - 提供增益或减益效果（轻功提纵、剑意涌动等）
- **恢复卡** - 回复生命值（金疮药、回春术、九花玉露丸等）
- **消耗卡** - 一次性使用的强力效果（绝世武功、绝世神功等）

**卡牌稀有度**：普通、罕见、稀有、传说

**卡牌升级**：提升效果值、降低消耗

### 敌人系统

**12+ 种敌人**，分为 4 种类型：

- **普通敌人**：山贼、流浪武者、门派弟子、毒蛇等
- **精英敌人**：门派长老、江湖高手、黑衣杀手、毒王弟子等
- **Boss**：黑虎堂堂主、西域魔僧、武林盟主
- **隐藏敌人**：恶鬼（特殊精英）

**敌人意图系统**：提前预判敌人行动，制定策略

### 遗物系统

**20+ 种遗物**，分为 5 种类型：

- **战斗类**：剑意、毒龙心法、黑虎爪、金钟罩等
- **成长类**：江湖经验、天道酬勤、武学秘籍、武林通缉
- **资源类**：内力丹、九转还魂丹、千年灵芝、聚宝盆
- **特殊类**：盟主令、剑谱残卷、丐帮袋、易筋经、武林至尊
- **组合遗物**：少林三宝、武当三丰（套装效果）

### 商店系统

- **卡牌**：根据稀有度定价（50-300 金币）
- **遗物**：根据稀有度定价（100-500 金币）
- **药水**：回血药水（30 金币）
- **服务**：移除卡牌（100 金币）

### 事件系统

- **老者赠剑**：接受剑、请教武学或婉拒
- **毒蛇洞**：探索、绕行或放火烧洞
- **江湖酒馆**：喝酒、打听消息或离开
- **武林秘籍**：购买或偷取秘籍

### 休息点

- **休息**：恢复 30% 生命值
- **修炼**：升级一张卡牌
- **继续**：直接进入下一节点

### 存档系统

- **手动存档**：随时保存游戏进度
- **自动存档**：每分钟自动保存
- **存档信息**：显示职业、等级、层数、金币、遗物数、卡组大小
- **导出/导入**：支持存档文件导出和导入
- **清空存档**：一键清除所有存档
