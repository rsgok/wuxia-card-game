# 江湖行 - 武侠 Roguelike 卡牌游戏

一个基于网页的 Roguelike 卡牌对战游戏，灵感来自 Slay the Spire。

## 项目结构

```
wuxia-card-game/
├── index.html              # 主页面
├── src/
│   ├── css/
│   │   └── style.css       # 样式表
│   └── js/
│       ├── data/
│       │   ├── cards.js    # 卡牌数据
│       │   ├── enemies.js  # 敌人数据
│       │   └── relics.js   # 遗物数据
│       ├── models/
│       │   ├── player.js   # 玩家类
│       │   └── enemy.js    # 敌人类
│       ├── systems/
│       │   ├── battle.js   # 战斗系统
│       │   └── deck.js     # 卡组管理
│       ├── ui/
│       │   └── gameUI.js   # 游戏UI
│       └── game.js         # 游戏主逻辑
├── assets/                 # 资源文件（图片、音效）
└── README.md              # 本文件
```

## 快速开始

1. 在浏览器中打开 `index.html` 文件
2. 选择你的武学门派（剑客、拳师、医师）
3. 使用卡牌击败敌人
4. 获得经验、新卡牌和遗物，挑战更强的敌人

## 游戏特性

### 三个武学门派

- **剑客** - 专精连击和爆发伤害
- **拳师** - 擅长防御和反击
- **医师** - 擅长治疗和状态控制

### 核心玩法

- 回合制卡牌战斗
- Roguelike 随机地图和奖励
- 遗物系统构建独特玩法
- 卡组构建策略

### 卡牌类型

- **攻击卡** - 造成伤害
- **防御卡** - 获得护甲
- **能力卡** - 提供增益或减益效果
- **恢复卡** - 回复生命值
- **消耗卡** - 一次性使用的强力效果
