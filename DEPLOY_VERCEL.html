步骤 1

在 GitHub 创建仓库

首先需要在 GitHub 上创建一个仓库来存储代码。

🔗 点击这里创建 GitHub 仓库
  1. 仓库名称填写：wuxia-card-game
  2. 选择 Public（公开）或 Private（私有）
  3. 勾选 "Add a README file" 可选
  4. 点击 Create repository 按钮

⚠️ 注意：仓库名必须完全一致：wuxia-card-game

步骤 2

推送代码到 GitHub

现在将本地代码推送到刚创建的 GitHub 仓库。

cd wuxia-card-game
git push -u origin main

执行后，你会看到类似这样的输出：

Enumerating objects: 123, done.
Counting objects: 100% (123/123), done.
Delta compression using up to 8 threads
Compressing objects: 100% (100/100), done.

Total 123 (delta 45), reused 0 (delta 0), pack-reused 0
To github.com:rsgok/wuxia-card-game.git
   * [new branch]      main -> main

✅ 成功标志：看到 * [new branch] main -> main 表示推送成功！

步骤 3

在 Vercel 部署

最后一步，使用 Vercel 快速部署网站。

🌐 点击这里访问 Vercel
  1. 用你的 GitHub 账号（rsgok）登录 Vercel
  2. 点击 Add New Project 按钮
  3. 在 "Import Git Repository" 下找到 rsgok/wuxia-card-game
  4. 点击 Import 按钮
  5. Vercel 会自动检测项目配置，点击 Deploy

等待几分钟部署完成后，你会得到一个链接：

🎉 https://wuxia-card-game.vercel.app

这就是你的游戏网址！

💡 常见问题

Q: 推送代码时提示 "remote origin already exists"？
 A: 没关系，继续执行命令即可。

Q: Vercel 部署失败？
 A: 检查 GitHub 仓库名是否为 wuxia-card-game。

Q: 如何更新游戏？
 A: 修改代码后，执行 git push，Vercel 会自动重新部署。
